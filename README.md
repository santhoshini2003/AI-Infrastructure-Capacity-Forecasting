# AI-Based IT Infrastructure Capacity & Forecasting Dashboard

## Project Overview
An interactive data analytics project developed using Databricks and Power BI to monitor IT infrastructure performance, analyze resource utilization, identify infrastructure risks, and support capacity planning.

## Project Objectives
- Analyze IT infrastructure performance and resource utilization.
- Monitor CPU, memory, and storage usage.
- Identify infrastructure incidents and potential risks.
- Analyze capacity requirements and forecasting insights.
- Build interactive dashboards for data-driven decision-making.

## Tools & Technologies
- **Databricks** – Data storage, processing and analytics
- **SQL** – Data querying and analysis
- **Microsoft Power BI** – Interactive dashboard development
- **Power Query** – Data preparation
- **DAX** – Measures and KPI calculations
- **CSV** – Dataset format

## Project Workflow

1. Uploaded and managed infrastructure datasets in Databricks.
2. Used SQL to query and analyze infrastructure data.
3. Prepared data for reporting and visualization.
4. Connected the data with Power BI.
5. Developed interactive dashboards to monitor infrastructure performance and capacity.

## Dataset Description

| Dataset | Description |
|---|---|
| Infrastructure_Master | Infrastructure details |
| Infrastructure_Metrics | Performance metrics |
| Infrastructure_Incidents | Incident information |
| Capacity_Planning | Capacity planning data |
| Data_Dictionary | Dataset field descriptions |
